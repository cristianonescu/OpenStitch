## Owner's rules and rulings added (keep them)

- **No private details in the repo:** scan the tree, the release notes and every batch diff for
  keys, tokens, env values, local paths, notes-folder ids and personal emails before tagging.
- **Wording:** the image wizards' default is "PE-DESIGN-compatible mode", OpenStitch's
  reimplementation of PE-DESIGN 11's method. Never a bare "PE-DESIGN mode" in docs or captions.
- **alpha.9 is B16.1**, the image-similarity work. It runs on the Mac as four tracks: colour
  engine and dialog; Photo Stitch; Auto Punch; Cross Stitch and Design Center. A test session
  checks it before the release. On Windows, the image dialog is checked and the gallery and
  screenshots are regenerated at the gate.
- **Density in OpenStitch mode:**
  - At most 2.1 needle points/mm² on average, and no 10 × 10 mm window above 3.0 (trim tie-ins
    counted).
  - Photo Stitch 2: average at most 3.3, and no window denser than the PE-DESIGN-compatible
    mode's densest on the same image. Its ≥ 75 target is dropped; the best measured is about 48.
  - Auto Punch: a normal single-layer fill or satin counts as compliant.
- **Other choices:**
  - Photo Stitch trims are the user's choice (fewer or all, defaulting by Fidelity).
  - Saliency at β 1.5.
  - Cross Stitch fills crosses by default, with part-crosses as an option.
  - Design Center bold lines are sewn as parallel running lines; its threshold comes from the
    image (Otsu).
  - Auto Punch in OpenStitch mode sews the background by default (the user can turn it off),
    keeps satin for strokes up to 2.5 mm and drops regions under 2 mm².
  - Thread sources: every built-in chart (Brother, Madeira Polyneon, Isacord 40, Sulky Rayon 40,
    Robison-Anton Rayon and Polyester 40) or the user's own threads. Brand data comes only from
    each manufacturer's own published chart, with sources in `research/beyond/thread-charts.md`.
    A Brothread chart is wanted but not in the repo yet.
  - Fidelity: the dialog starts on Standard; High allows up to 24 colours (Photo Stitch 2 keeps
    4) and may pick threads the user does not own, listing them to buy.
  - Photo Stitch 1 dithers only where the image is tonal (flat threshold ΔE 12).
- **Open issues are mandatory work:** every plan and every batch says which open issues it
  moves forward, and issues are worked down, not left behind roadmap items. Blocked issues
  (#134, #130) stay listed in every plan.
- **Cleanup reminder:** at every release gate and wrap-up, list stale sessions, worktrees and
  free disk space, and offer to clean up. Act only on the owner's yes.
- **Shared rule set:** the Windows and Mac coordinators exchanged their rules and lessons; both

## How it was run (lessons)

- **Batching for B16.1:** the Mac builds the integration branch and opens the PR. Windows checks
  it (private scan, wording, no compat or reference changes) and merges on green, then closes the
  originals as included. Golden hashes are regenerated once per batch. Shared docs come in one
  commit per batch, before the merge.
- **CI capacity:** GitHub runs few macOS jobs at once.
  - Cancel feature-branch CI before a release build (the release run starved behind 15 runs).
  - Use `gh run rerun <id> --failed` afterwards.
- **Gate scripts:** check whether a stopped gate script already pushed the tag before restarting
  it.
- **Merge watcher:** treat "skipping" checks as passing (#258 waited because of one).
