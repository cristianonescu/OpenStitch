## Lessons (also in the coordinators' memory)

- **No hanging PRs.** #299 stayed open for seven hours: a draft kept local, a push that started no
  CI because the PR conflicted, and a wait-for-a-free-build loop that never matched. After every
  push, check that CI started. Comment on the PR at least hourly. The oldest PR with green checks
  merges first.
- **Run the touched crates' full tests, not `--lib`,** before pushing an output change (a stale
  golden pin went red in CI).
- **A release freeze stops merges, never development;** keep every session slot filled.
