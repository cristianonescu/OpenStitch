# Getting started with OpenStitch

Your first design takes a few minutes. Each step has a button at the top of this page that starts it.
Help ▸ Getting Started opens this page again at any time.

## Draw a shape

Pick **Rectangle** (or press R) and drag on the white Design Page. OpenStitch fills the shape
with stitches at once. Circles, open and closed lines and curves sit beside the rectangle on the
**Home** tab. Click a shape to select it; drag its handles to resize or turn it.

## Add lettering

Open **Text ▸ Text…**, type a word, pick a font and a height, and place it on the page. Change
the font or the letters later from the **Text Attributes** pane.

## Watch it sew

The **Stitch Simulator** sews the design needle by needle, in the order the machine will. The
**Sewing Order** pane on the left changes that order; the **Sewing Attributes** pane on the right
changes how the selected shape is sewn (fill or satin, density, angle, underlay).

## Save

**Save** keeps the design as an OpenStitch `.osd` file, with every shape and its settings, so it
can be changed later.

## Export for the machine

**File ▸ Export** writes the file your machine reads: PES for Brother and Baby Lock, DST, JEF,
EXP, VP3 and more. Copy it to the machine's USB stick.

## Open a sample

**File ▸ Open Sample** opens a ready design from the kit that comes with OpenStitch: a satin and
fill sampler, shapes, frames, lettering, monograms or appliqué. It opens as a new untitled
design, so your changes never touch the kit; Save asks for a name.
