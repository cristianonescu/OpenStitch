## What changed since alpha 16

### Licences

- **The browser version shows its third-party notices and licences (#1175).** Help ▸ About in the
  browser version links the third-party notices and the MIT and Apache licences, which the page
  now publishes beside itself. The desktop packages already carry them beside the program.
- **The notices are checked on every change (#1175):** CI fails a pull request whose
  `THIRD_PARTY_NOTICES.md` no longer lists every crate the programs are built from, and prints
  any licence outside the permissive set.
