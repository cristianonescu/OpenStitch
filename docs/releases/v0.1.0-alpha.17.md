## What changed since alpha 16

### Fixes

- **A template never saves over your project (#1179).** Opening a template in the Template
  Wizard replaced the design but kept the file name of the project that was open. The next Save
  then wrote the template over that project.
  - A template now opens as File ▸ New does: an untitled design, so Save asks for a name. If you
    have unsaved changes, you are asked about them first. With "Open designs in tabs" on, the
    template gets its own tab.
  - The same holds when the Assistant or a `--listen` client opens a template.
  - Test swatches never changed the open design or its file, and they still do not. Their
    window's **Open it** now opens the swatch as File ▸ Open does, asking about unsaved changes
    first, where it used to replace the design without asking.
