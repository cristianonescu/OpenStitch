# OpenStitch 0.1.0 alpha 17

## Fixed

- **macOS: Finder and Quick Look show stitched thumbnails again** for `.pes`, `.osd` and the
  other embroidery files OpenStitch reads (#1182). The thumbnail extension now draws with the
  renderer linked into it; macOS does not let it start the helper program it used before, so
  every thumbnail had failed and Finder showed the plain document icon.
