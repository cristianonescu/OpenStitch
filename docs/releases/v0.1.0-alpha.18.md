# OpenStitch 0.1.0 alpha 18

The eighteenth alpha of OpenStitch, an independent, cross-platform embroidery design application
for macOS, Windows and Linux, built to work with Brother machines and with designs made in
PE-DESIGN 11. OpenStitch is not affiliated with Brother Industries.

Alpha 18 is a large release:
- **Fills, nets, satins and candlewick sew closer to PE-DESIGN.** Designs sew differently than in
  alpha 17; see "Changed output".
- **Select Point works as PE-DESIGN's,** on shapes and on stitch patterns, with direction lines.
- **An object right-click menu and PE-DESIGN's object keys.** Join Lines moved to Ctrl+Shift+J.
- **Everything is within reach in a small window.**
- **The browser version has the Assistant,** crash recovery and a phone layout.

**It is still an alpha for testing, not for production work.** Read "Before you sew" below.

## Changed output

Designs sew differently than in alpha 17. Shapes and settings are unchanged; the stitches are
worked out again:
- **Fill rows as PE-DESIGN sews them** (#1131, #1088, #1144): row count, one needle point per
  corner, the end point, and PE-DESIGN's page-wide needle grid. A 40 mm square changes by up to
  about 20 of 2000 points. Moving a fill re-phases its points, so its count can change.
- **Satin lettering:** A, H, K, T travel under the stem as PE-DESIGN does (#938); W and w sew their
  inner arms as one block (part of #1064).
- **Nets** travel along the outline in PE-DESIGN's order (#1043, #1071); a new zigzag net has under
  sewing on by default (#1239). Saved nets keep their setting.
- **Candlewick knots** have PE-DESIGN's points at every Size (#1236, #1237).
- **Satin on Closed Straight Line shapes** (a U, an H, a sharp bend) sews PE-DESIGN's needle points
  (#1154).
- **PES:** a plain fill writes its own direction line into PES 0110 instead of 45 degrees (#1273).
- **Calibration kit:** `satin-and-underlay`, `t1-swatches` and `t2-alternating-rows` changed;
  earlier sew-outs of them no longer match.
- **Projects:** saved `.osd` projects now store outline point kinds (#1258); alpha 18 reads them.

## What changed since alpha 17

### Select Point (Point Edit)

- **PE-DESIGN's point menu** (#1258): To Straight, To Curve, To Smooth, To Symmetry, To Cusp, Split
  at Point, Delete; a new Edit Point group on the Shapes tab.
- **Editing** (#1260): one click adds a point; drag box, Ctrl+click and Shift+click select several,
  across selected shapes; arrow keys move them 0.5 mm; Delete; Open and Close; Alt+drag joins or
  closes open lines.
- **Direction lines** (#1273): Add and Delete Direction Line; a fill fans between several lines, as
  PE-DESIGN sews it; read and written in PES 0110.
- **Stitch patterns** (#1272): click adds a needle point; Tab, Home, End and Ctrl/Shift+arrow stay in
  the colour block; right-click a needle point for Split at Point and Delete.
- Split at Point and Open cancel hole sewing and release fitted text (#1271).

### Object menu and shortcuts

- **Right-click an object** for PE-DESIGN's object menu: cut, copy, paste, flip, Size and Rotate by
  numbers, centre, align, overlap, emboss/engrave, cut-and-sew, Sewing Attributes (#1288).
- **New keys:** Flip Vertical **Ctrl+H**, Flip Horizontal **Ctrl+J**, Center **Ctrl+M** (macOS
  **Cmd+Shift+H**, **Cmd+J**, **Cmd+Shift+M**).
- **Join Lines moved from Ctrl+J to Ctrl+Shift+J.** A saved shortcut of yours that is now a default
  stays yours; the editor says so once.
- Paste lands on the originals, as in PE-DESIGN; Ctrl+D's copy lies 5 mm right and down.
- New: **Join Lines** and **Break Apart** (#744).

### Small windows

- Menus, panes and dialogs scroll; OK and Cancel stay in view; checked at ten sizes down to
  640 × 400 at 200 % text (#1276). Folded panes start below 780 points (was 640).
- **Escape closes an open pop-up first.**
- The page stays in view after a resize (#1266).

### File formats and image tools

- PES 0110: candlewick, stem and chain values in their own fields (#1160, #1237); out-of-range values
  are clamped on import and noted (#1125).
- **Floppy disk images** for older machines (#876).
- GIF and WebP open in image tools (#832); Auto Punch outlines never cross (#1137); Cross Stitch can
  follow pixel art's grid (#994).

### Browser version

- **The Assistant** (#766), with your own key or a local model.
- Crash recovery, samples, phone layout, a smaller download (#831, #833, #834, #696).
- While the canvas has focus, the editor's Ctrl shortcuts take precedence (never Ctrl+C/X/V).

### Assistant, editing and checks

- Panel commands for scripts (#1180); a coding agent continues its own session (#1170).
- Check Design runs in the background on large designs (#1127) and judges blend layers together
  (#1120); the Sewing Order list stays smooth (#1192) and its rename and filtered drag are fixed
  (#1220, #1221).

### Windows/macOS and docs

- macOS Quick Look check retries after registration (#1249); the private scan reads binary files
  (#1226, #1213). Competitor scans in the docs.

## How it was tested

- **Automatic:** CI runs the full test suite on macOS, Windows and Linux, the browser page tests in
  three browsers, and the release smoke test.
- Stitch changes were measured against PE-DESIGN 11.50 captures; the kit was regenerated.
- **Not checked by hand:** macOS hand checks were not run for this release (the Mac was off); CI ran
  the macOS tests.

## Before you sew

- **Do a test sew-out on scrap fabric.**
- **Known issues:**
  - Direction-line fills: 7 of 22 zones are outside tolerance against PE-DESIGN (#1287; accepted).
  - Browser on a Mac: Flip Vertical and Center keys are taken by the system; use the menu (#1292).
  - A machine file opens as one pattern with colour blocks; PE-DESIGN makes one per colour (#1289).
  - In a window lower than about 130 points, a dialog's button row scrolls with the content.
  - **macOS:** double-clicking a file in Finder doesn't open it in OpenStitch yet; use File ▸ Open.
  - Not verified on PE-DESIGN's screen: some Select Point modifier keys, Alt-connect and Ctrl+End;
    the Rotate dial's direction; Open/Close on two closed shapes; the menu on text. These keep
    OpenStitch's own behaviour.
  - Planned (Future): Split at Point and Select Point follow-ups #1279–#1284.
  - Browser Assistant cannot see pictures or import SVG yet (#1224, #1223).
  - Other differences: README "Known issues" and [docs/COMPATIBILITY_AUDIT.md](../COMPATIBILITY_AUDIT.md).
- **PES files left out of the release:** none.
- **Keep your original PE-DESIGN files.** Save OpenStitch's output under a new name.
