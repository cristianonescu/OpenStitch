## Changed output: the same design can sew differently

These defaults changed. Each item says how to get the old behaviour back where there is a way.

- **Every section start ties in, also after a lone needle point or a 0.1 mm first stitch (#1076):**
  - **What changed:** two kinds of run started without a tie-in that holds:
    - A run whose first piece is a single needle point, with the run's next piece close enough to be
      stitched to (an Auto Punch satin piece in the OpenStitch-mode storybook). The section opened
      with an untied 2.7 mm stitch. The point now starts the next piece, which ties in on it.
    - A run whose first stitch is between 0.1 and 0.15 mm (an Auto Punch fill in the
      PE-compatible storybook). It tied in by stepping that far and back, and a machine file's
      0.1 mm grid rounded the step onto its start. The tie-in now steps along the first stitch
      longer than 0.15 mm, which always lands on another grid point.
  - **What a sewer notices:** the kit's two Auto Punch storybooks had one thread end without a
    tie each and have none, as built and as exported PES. In the kit:
    - `image-tools/L-autopunch-storybook-openstitch.pes`: 95,056 → 95,061 stitches;
    - `image-tools/L-autopunch-storybook-pe-compatible.pes`: 113,916 → 113,921;
    - `fills/meander-tiles-2.pes`: 2,181 → 2,182;
    - `shapes/shape-tools.pes`: 4,484 → 4,485;
    - `lettering/monograms.pes`: needle points moved by a tie-in step, count unchanged (7,606).
    No trim is added or removed.
  - **Not affected:** a lone point farther from the next piece than a sewn connection (4 mm),
    which stays a move's landing as before, and lone points later in a run (a pulled fill row's
    end).
  - **Old behaviour:** none.
- **A plain net starts from the shape (#1071):**
  - **What changed:** a Net Fill region's lines start half a spacing in from the top-left corner
    of the shape's bounds, as PE-DESIGN 11.50's do, not from the page origin; and the needle
    steps the run pitch (2 mm) along each whole line, through its crossings, instead of from
    crossing to crossing (1.5 mm stitches at 3 mm spacing). On a 30 × 20 mm rectangle at
    Spacing 3.0 the needle points inside the shape are now PE-DESIGN's at 0°, 45° and 90°:
    280, 315 and 278 stitches against PE-DESIGN's 281, 336 and 281 (before: 344, 374, 316).
    The ready-to-sew kit's `fills/region-sew-types-2.pes` (a square net) goes from 4,675 to
    4,665 stitches, and `wizards/cutwork.pes` (the Cutwork wizard's net) from 3,541 to 3,303.
  - **Not affected:** a net with a reference point, which still starts there.
  - **Old behaviour:** none; set a reference point to place the net.
