## Changed output: the same design can sew differently

These defaults changed. Each item says how to get the old behaviour back where there is a way.

- **A stitch in place before a one-step tie-in on a Hoop Size page (#1013):**
  - **What changed:** on PE-DESIGN's Hoop Size page (a 100 × 100 mm page, or a page set by a hoop
    PE-DESIGN knows), each run whose tie-in is one 0.3 mm step out and back now starts with a
    stitch in place where the move lands, as PE-DESIGN 11.50 sews it: one needle point more per
    such run. Satin K at 8 mm: 136 → 137 needle points, and its first stitches now match
    PE-DESIGN's.
  - **Not affected:** runs with a three-step tie-in, designs on a Custom Size page (any other
    page size with no known hoop), an object's own ties (Finish), opened stitch files, and runs
    that already start with six stitches in place (no seventh is added).
  - **Old designs:** an `.osd` saved before this alpha has no page mode stored and opens on a
    Hoop Size page when its page is 100 × 100 mm or its hoop is a known one; its stitches change
    by this stitch in place only.
  - **Old behaviour:** start the design on a Custom Size page (`design.new` `pageMode: "custom"`).
    The editor has no Design Settings control for it yet.
- **Vertical text laid out as PE-DESIGN's (#1027):**
  - **What changed:** a vertical text's letters stand one text size apart, running down from the
    click, each capital hanging from the top of its cell, as PE-DESIGN 11.50 lays them out. Before,
    they were stacked by the font's vertical cell (1.2 em) and the column was centred on the
    click. "ABC" at 8 mm: 35.8 mm tall before, 24.4 mm now, PE-DESIGN's own height, and it starts
    at the click instead of above it. Vertical text can now be exported to PES 0110 as one column.
  - **Not affected:** horizontal text, and texts sized by capital height (older files), which keep
    the font's vertical metrics.
  - **Old behaviour:** none; move the text if a saved design relied on the old position.
- **Realistic view drawn without moiré (#1020):**
  - **What changed:** the screen only, not the stitches. The desktop editor's Realistic view
    draws its threads as one mesh with 4× multisampling, so zoomed-out fills no longer show light
    stripes, and it draws faster (a 112,000-stitch design: about 35 ms a frame against 100 ms).
    Dense fills look a little lighter at page fit (4–11 levels; the black ramp up to 22),
    closer to the sewn T1 swatches on white cotton. The ready-to-sew kit's previews were
    redrawn with it (render version 2, #920).
  - **Not affected:** the stitches and every file written; the web editor keeps the old drawing.
  - **Old behaviour:** set the environment variable `OPENSTITCH_NO_MSAA=1` before starting the
    editor (also useful on a remote desktop or a driver that draws multisampling wrongly).
