## Changed output: the same design can sew differently

These defaults changed. Each item says how to get the old behaviour back where there is a way.

- **A stitch in place before a one-step tie-in on a Hoop Size page (#1013):**
  - **What changed:** on PE-DESIGN's Hoop Size page (a 100 × 100 mm page, or a page set by a hoop
    PE-DESIGN knows), each run whose tie-in is one 0.3 mm step out and back now starts with a
    stitch in place where the move lands, as PE-DESIGN 11.50 sews it: one needle point more per
    such run. Satin K at 8 mm: 136 → 137 needle points, and its first stitches now match
    PE-DESIGN's.
  - **Not affected:** runs with a three-step tie-in, designs on a Custom Size page (any other
    page size with no known hoop), an object's own ties (Finish), opened stitch files, and runs
    that already start with six stitches in place (no seventh is added).
  - **Old designs:** an `.osd` saved before this alpha has no page mode stored and opens on a
    Hoop Size page when its page is 100 × 100 mm or its hoop is a known one; its stitches change
    by this stitch in place only.
  - **Old behaviour:** put the design on a Custom Size page: Design ▸ Design Settings ▸ Page ▸
    Custom Size, or `machine.set` `pageMode: "custom"` (`design.new` takes it too, #1056).
- **Vertical text laid out as PE-DESIGN's (#1027):**
  - **What changed:** a vertical text's letters stand one text size apart, running down from the
    click, each capital hanging from the top of its cell, as PE-DESIGN 11.50 lays them out. Before,
    they were stacked by the font's vertical cell (1.2 em) and the column was centred on the
    click. "ABC" at 8 mm: 35.8 mm tall before, 24.4 mm now, PE-DESIGN's own height, and it starts
    at the click instead of above it. Vertical text can now be exported to PES 0110 as one column.
  - **Not affected:** horizontal text, and texts sized by capital height (older files), which keep
    the font's vertical metrics.
  - **Old behaviour:** none; move the text if a saved design relied on the old position.
- **Realistic view drawn without moiré (#1020):**
  - **What changed:** the screen only, not the stitches. The desktop editor's Realistic view
    draws its threads as one mesh with 4× multisampling, so zoomed-out fills no longer show light
    stripes, and it draws faster (a 112,000-stitch design: about 35 ms a frame against 100 ms).
    Dense fills look a little lighter at page fit (4–11 levels; the black ramp up to 22),
    closer to the sewn T1 swatches on white cotton. The ready-to-sew kit's previews were
    redrawn with it (render version 2, #920).
  - **Not affected:** the stitches and every file written; the web editor keeps the old drawing.
  - **Old behaviour:** set the environment variable `OPENSTITCH_NO_MSAA=1` before starting the
    editor (also useful on a remote desktop or a driver that draws multisampling wrongly).
- **Direction now turns a zigzag net (#1043):**
  - **What changed:** a zigzag net region turns by its Direction, as PE-DESIGN 11.50 does; before,
    it always sewed on the page axes. Switching a region to zigzag net now starts it at
    Direction 0, PE-DESIGN's default for the type (a 45° fill switched over used to keep 45°).
    The net starts where PE-DESIGN starts it: from the top-left corner of the shape's bounds
    on the page, half a band in along both turned axes, so its bands lie where PE-DESIGN's do
    at every Direction (within 0.05 mm). PE-DESIGN also sews the part of a band that reaches
    into the shape from a line running outside it; OpenStitch does not yet, so off the axes
    it sews fewer stitches: on a 30 × 20 mm rectangle 945, 871, 828 and 718 at 30°, 45°, 90°
    and 180°, where PE-DESIGN sews 1,148, 1,141, 850 and 923 (to follow, #1043).
  - **Not affected:** nets at Direction 0 (stitch for stitch as before), and nets saved by older
    versions, which load at Direction 0 so they keep their look.
  - **Old behaviour:** set the net's Direction to 0.
- **A switch to net fill starts at Direction 0 (#1054):**
  - **What changed:** switching a region to Net Fill now sets its Direction to 0, as PE-DESIGN
    11.50 does (a 45° fill switched over used to keep 45°, so its net sewed diagonally). An
    angle given with the switch is kept. The ready-to-sew kit's `fills/region-sew-types-2.pes`
    and the `region-types` example make their net this way, so their net now sews on the page
    axes: the kit file 4,554 → 4,532 stitches, the example's honeycomb net 16,070 → 16,068 for
    the whole design.
  - **Not affected:** nets saved by older versions keep their Direction, since they really
    sewed at it; the Cutwork wizard's net keeps the direction set in the wizard.
  - **Old behaviour:** set the net's Direction to 45 after the switch.
- **Programmable fill: Frequency only with Base sewing (#1042):** the Frequency control is shown
  only while Base sewing is on, as PE-DESIGN greys it otherwise; it staggers the base sewing
  only, so it never changed anything without it. No stitches change.
- **Stripes line: no "Period" control (#1049):** stripes are running rows along the band and
  have no period, so the control, which changed nothing, is gone. No stitches change.

- **The calibration cards are not the files that were sewn (#291):**
  - **What changed:** nothing new for the swatch rows in this alpha. The T1 card was sewn on
    2026-11-03 (main 4cf8b7a) and 2026-11-04 (4cf8b7a or later), but its file has changed since:
    in #299 and substantially in #634 (alpha.12: 4,870 of 5,193 records). In this alpha, #1013
    added only stitches in place before one-step tie-ins, and #938 changed only the left end of
    the "T1" and "T2" labels' T bar (2 runs of records), not the swatch rows. The T2 card and the
    satin and under sewing card have no sew-out yet.
  - **Old behaviour:** `git show 4cf8b7a:examples/sew/calibration/t1-swatches.pes` is the file
    the scans were sewn from.

- **Every letter piece ties in (#1032):**
  - **What changed:** a run that starts on a near-duplicate point (Pacifico's i, a stroke's first
    rung 0.01-0.02 mm from its lead) used to tie in by stepping out that far and back, which the
    writer sews as one needle point, so the piece started untied. The tie-in now steps along the
    first stitch longer than 0.1 mm, PE-DESIGN's 0.3 mm out and back. The kit's fonts-and-text
    had 4 untied letter starts (Pacifico's "ific") and has none; two Auto Punch designs lose a few
    untied starts (storybook 97 to 95, balloon 4 to 3; the rest are Auto Punch ends, #1032).
  - **Not affected:** runs whose first stitch is longer than 0.1 mm.
  - **Old behaviour:** none.

- **SHV preview size as PE-DESIGN's (#989):**
  - **What changed:** the SHV thumbnail is twice the design's half-width in millimetres,
    rounded, plus a pixel each side, and the same for its height, as PE-DESIGN 11.50 writes it.
    A 59.0 or 59.5 mm wide design now gets a 62 px preview where it got 61, and a 69.4 mm one
    72 px where it got 71. The stitch records do not change, and a machine sews the same.
  - **Not affected:** a side whose length in whole millimetres (rounded down) is even keeps its
    size; an odd one grows by a pixel. The pixels are still drawn at one a millimetre:
    PE-DESIGN's own drawing follows no rule we could fit.
  - **Old behaviour:** none.
