# OpenStitch 0.1.0 alpha 10

The tenth alpha of OpenStitch, an independent, cross-platform embroidery design application for
macOS, Windows and Linux, built to work with Brother machines and with designs made in
PE-DESIGN 11. OpenStitch is not affiliated with Brother Industries.

Alpha 10 adds a **ready-to-sew kit**: 35 embroidery files made by OpenStitch, ready to copy to a
machine, packaged with the editor and opened from **Help ▸ Ready-to-Sew Designs**. The stitch
output is unchanged from alpha 9. **It is still an alpha for testing, not for production work.**
Read "Before you sew" below.

## Downloads

| System | File | Notes |
|---|---|---|
| macOS 11 or later (Apple Silicon and Intel) | `OpenStitch-v0.1.0-alpha.10-macos-universal.zip` | Unzip and move `OpenStitch.app` to Applications |
| Windows 10/11 (x86-64) | `OpenStitch-v0.1.0-alpha.10-windows-x86_64.msi` | Installer; adds `.osd` and "Open with" for `.pes` |
| Windows, portable | `openstitch-*-windows-x86_64.zip` | Unzip and run `openstitch.exe` |
| Linux x86-64 | `OpenStitch-v0.1.0-alpha.10-linux-x86_64.AppImage` | `chmod +x`, then run it; `--install-integration` adds the menu entry and file types |
| Linux x86-64 | `OpenStitch-v0.1.0-alpha.10-linux-x86_64.tar.gz` | Editor with `install.sh`, desktop entry, MIME types and thumbnailer |
| Command line (all systems) | `openstitch-cli-*` | `stitchtool` (scripting) and `openstitch-mcp` (MCP server) |
| Checksums | `SHA256SUMS` | SHA-256 of every file above; the editor's updater checks downloads against it |

**Updating from alpha 4 to 9:** start the editor and accept the update dialog, or use Help ▸
Check for Updates. Alpha 3 and earlier must be replaced by hand with a package above.

## The builds are not code-signed

- **macOS:** the first time, right-click `OpenStitch.app` and choose **Open**, then **Open**
  again. Alternatively, run `xattr -dr com.apple.quarantine /Applications/OpenStitch.app`.
- **Windows:** in the SmartScreen prompt, choose **More info → Run anyway**.

## What changed since alpha 9

### Ready-to-sew designs ➕

- **35 PES files in 8 groups** ([examples/sew](../../examples/sew)):
  - calibration designs and machine checks;
  - fills, lines, shapes and lettering;
  - the wizards: appliqué, patch, cutwork and background fill;
  - the image tools in both modes.

  Each comes with a preview, its threads and how to sew it, and `manifest.json` lists every
  file's size, stitch count, threads and SHA-256.
- **Sized for the Brother NV880E** and its 100 × 100, 150 × 150 and 260 × 160 mm hoops. Other
  machines that read PES can sew them in a hoop at least as large.
- **Help ▸ Ready-to-Sew Designs** opens the kit packaged with the editor in the file manager
  (Explorer, Finder or Files). **Help ▸ Ready-to-Sew Designs Online** opens it on GitHub.
- **In every package:** the macOS app, the Windows installer and portable zip, and the Linux
  AppImage and tar.gz. The Flatpak has no packaged kit, so the menu opens the kit on GitHub.
- **Calibration:** sewing the calibration designs and
  [sending the photos](../../examples/sew/README.md#sending-results) helps tune OpenStitch to real
  thread and fabric.

### Tools

- `tools/gallery.py` now also runs on macOS
  ([#271](https://github.com/cristianonescu/OpenStitch/issues/271)).
- `tools/sew_kit.py` regenerates the kit and its manifest.

## Before you sew

- **Do a test sew-out on scrap fabric** before using a design on anything that matters. The kit's
  designs are the first OpenStitch files meant for a machine, and none has a recorded sew-out yet.
  Its README says how to sew them and how to send the results.
- **Known differences from PE-DESIGN 11:** unchanged since alpha 9. See "Known issues" in the README
  and [docs/COMPATIBILITY_AUDIT.md](../COMPATIBILITY_AUDIT.md).
- **Keep your original PE-DESIGN files.** Save OpenStitch's output under a new name.
- **macOS:** double-clicking a file in Finder does not open it in OpenStitch yet.

## Feedback

Please open an issue for anything that sews differently from what you expect, crashes, or works
differently from PE-DESIGN 11. Attach the `.osd` or exported file and say which machine you
used.
