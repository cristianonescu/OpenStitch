# Pattern-block redaction of the committed PE-DESIGN captures (2026-11-14, #1060)

PE-DESIGN 11.50 writes its default decorative fill pattern (53 polylines, size 10000) into the
pattern block of every shape it saves (`CEmbLine` body bytes 386 on). That is Brother content, so
`tools/redact_pattern_blocks.py --write` rewrote every such block in the committed captures to
OpenStitch's placeholder rows at the same point counts. The file length, every offset and every
byte outside the blocks (the PEC stitches included) are unchanged; the last column is the SHA-256
of everything outside the rewritten blocks, the same before and after. 495 blocks in 332
files, all of one content; a second run finds none. The formats test
`committed_pes_files_list_only_the_projects_own_patterns` fails on any committed block that is
neither placeholder rows nor the project's own tiles.
